Strategy Settings

Strategy logic:
Start with the Starting Quantity and BUY. After TARGET: the trade closes, direction flips, and the NEXT call quantity is reset to Starting Quantity. After STOP LOSS: direction flips. Actual loss = previous quantity × SL. Recovery quantity = actual loss ÷ Recovery Points, rounded UP to the Starting Quantity decimal precision. That recovery quantity is added to the previous quantity for the NEXT call. Example: 0.01 × 250 = 2.5; 2.5 ÷ 400 = 0.00625 → 0.01; next quantity = 0.02. A call is never created with zero quantity. The same quantity-transition engine is used for every trade and the backtest runs a quantity-chain audit before showing PASS.
